# Why the quintic residual module does not lift on the same finite group

The degree-ten construction identifies `M=ad⁰(E[5])` with a twisted
deleted five-point module for `G=PGL₂(F₅)=S₅`. It computes residual
cohomology. The following explicit obstruction rules out extending that
construction by simply replacing F₅ with Z/25Z while retaining G.

**Proposition.** No free rank-three Z/25Z representation of G reduces
to M. Already its restriction to the cyclic subgroup generated by
`u=[[1,1],[0,1]]` has no such lift. For the actual curve a=-157469,
the projective mod-25 image is the full group PGL₂(Z/25Z), of order
15,000. Its kernel over the projective mod-five image has order 125.

The first assertion is stronger than saying that the particular
deleted-permutation formula fails: it excludes every rank-three free
lift on this same group. It does not obstruct the actual Tate-module
representation, whose finite Galois quotient changes at level 25.
These are elementary representation-theoretic consequences, not a new
Selmer computation or a claim of priority for lifting theory.

## 1. Every possible matrix lift fails the order-five relation

In the basis e,h,f of trace-zero two-by-two matrices, u acts by

    U = [1 3 4; 0 1 1; 0 0 1].

Use these entries as an integral matrix. Every matrix reducing to U
modulo 5 is `U+5B` modulo 25, for a three-by-three matrix B over F₅.
The noncommutative first-order expansion gives

    (U+5B)^5 = U^5 + 5 sum_(i=0)^4 U^i B U^(4-i)  (mod25).

The two terms, divided by 5 where appropriate, are

    C=(U^5-I)/5 = [0 3 0; 0 0 1; 0 0 0]           (mod5),
    sum_(i=0)^4 U^i B U^(4-i) = 4 B_31 E_13        (mod5).    (1)

For completeness, put N=U-I, so N³=0. Expanding each factor in
the sum using `U^i=I+iN+binom(i,2)N²` gives the second identity;
equivalently it can be checked on the nine elementary matrices B.
Only the `(1,3)` entry of the correction can change. In particular
every possible lift has fifth-power entries `(1,2)=15`, `(2,3)=5`
modulo 25 and cannot have fifth power I.

The generator of C₅ must have fifth power I in any representation.
This contradiction proves the no-lift assertion. It also applies if
the residual representation is given only up to conjugacy: lift the
change-of-basis matrix to GL₃(Z/25Z) and conjugate first.

## 2. The actual projective mod-25 image

The projective mod-five image of the actual curve is G, as proved by
the exact Frobenius argument in [the transgression note](adjoint_transgression_repair.md).
The kernel of

    PGL₂(Z/25Z) -> PGL₂(F₅)

is the additive group `M₂(F₅)/F₅ I`, identified with M by subtracting
half the trace. Its conjugation action is the adjoint action.
If H is the actual projective mod-25 image, its intersection with
this kernel is a G-stable F₅-subspace.

This G-module is irreducible. The diagonal element diag(2,1) acts
on e,h,f with the three distinct weights 2,1,3. Polynomial projectors
in this diagonal action show that every nonzero invariant subspace
contains one of these basis vectors. Conjugation by `v=[0,1;3,0]`
interchanges the e and f lines, while u sends h to `h-2e` and sends
f to `f+h-e`. Thus any one of the three vectors generates M.

Choose an element of H above u. Every projective lift of u has fifth
power represented by `I+5e`: changing a standard lift by `I+5B`
contributes the adjoint norm, which is zero in the scalar quotient.
The explicit identity and all 125 trace-zero kernel representatives
were checked in the earlier transgression certificate. Therefore
H intersects the kernel nontrivially. Irreducibility makes that
intersection the whole kernel. Surjectivity modulo five now gives

    H=PGL₂(Z/25Z),   |H|=120*125=15,000.

In particular, if K_5 and K_25 are the projective splitting fields,
then `[K_25:K_5]=125`. The splitting field of ad⁰(E[25]) is K_25:
an invertible two-by-two matrix acting trivially on all trace-zero
endomorphisms is scalar, since it commutes with e,h,f and 2 is a unit.
Moreover `Ad(I+5e)=I+5 ad(e)` is nontrivial. Thus the new kernel
really acts on the rank-three coefficient module.

This is the familiar congruence-kernel lifting phenomenon in this
explicit example. General results of this type go back to Serre;
see Lombardo, *Bounds for Serre's open image theorem for elliptic
curves over number fields*, Lemma 3.15, for a standard lifting lemma.
The elementary argument above suffices for the projective level 25
statement and does not assume a computed degree-15,000 number field.

## 3. Consequence for the remaining computation

The existing degree-ten ray characters still give the correct residual
space and the necessary local zero condition at 19. But lifting a
character on that same field with a constant S₅ action cannot supply
ad⁰(E[25]): the required rank-three S₅ module does not exist. Any
integral lifting algorithm must instead account for the nontrivial
congruence-kernel action, through larger coefficient fields or genuine
deformation/extension data.

The obstruction is to lifting the **coefficient representation on a
fixed finite quotient**. It does not imply that an individual global
cohomology class satisfying the local condition at 19 cannot lift,
and it supplies no criterion for that global lifting problem.
In particular, it does not evaluate delta₅(W) or Theta₅(e₃₇).

`scripts/check_adjoint_no_same_group_lift.py` checks (1) on all nine
matrix directions and verifies the first-order formula modulo 25.
It also verifies the 125 projective lifts, the adjoint kernel witness
and the irreducibility identities. Linearity in B proves the assertion
for all 5⁹ possible rank-three lifts without enumerating them.
