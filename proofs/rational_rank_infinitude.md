# Infinitely many rational parameters with Jacobian rank two

## Statement and source

There are unconditionally infinitely many a in Q∩(−1,3) for which
E_a: Y²=X³+(a−3)X²−(a−3)X
has rank one over Q. Their smooth reciprocal curves
C_a: y²=x⁶+a x⁴+a x²+1
have Jacobian rank two, and include infinitely many geometric isomorphism classes.

The external input is David Zywina, *Rank one elliptic curves and rank stability*, arXiv:2505.16960v1 (22 May 2025), Section 1.1, Theorem 1.5, Lemma 4.1 and the distinct-j argument in Section 4:
https://arxiv.org/html/2505.16960v1
https://arxiv.org/pdf/2505.16960v1
The relevant construction gives infinitely many rank-one specializations, with distinct j-invariants, of
F_t: v²=u³+4t(t+1)u²+2t(t+1)²(t−1)u
for rational 0<t<1. The specialization statement is read from that proof, not inferred merely from the abstract existence theorem. The rank/infinitude input is credited to Zywina; the argument below is an explicit transfer to this family.

## Exact transfer

Put A=a−3. The usual rational two-isogeny joins
E_A: Y²=X³+AX²−AX
and
E'_A: Y²=X³−2AX²+A(A+4)X.
It has kernel generated by (0,0), and away from it can be written
(X,Y) ↦ (Y²/X², −Y(X²+A)/X²).
The sign of the second coordinate only composes with elliptic negation. The discriminants are nonzero when A is neither 0 nor −4.

For t≠−1, set
A=−8t/(t+1), a=(3−5t)/(t+1), s=(t+1)/2.
Scaling E'_A by u=s²X, v=s³Y gives F_t exactly, because
s²(−2A)=4t(t+1),
s⁴A(A+4)=2t(t+1)²(t−1).
Thus E_A, E'_A and F_t have the same rational Mordell–Weil rank.

The change of parameter is Möbius with inverse t=(3−a)/(a+5). Its derivative is −8/(t+1)²; it maps (0,1) bijectively onto (−1,3). The external infinite collection therefore gives infinitely many distinct rational a in that interval with rank E_a(Q)=1.

## Genus-two consequence

The sextic discriminant is
disc_x(x⁶+a x⁴+a x²+1)=−64(a−3)^6(a+1)².
Every parameter under consideration therefore gives a smooth genus-two curve.

There are two degree-two maps
f1(x,y)=(x²+1,y),
f2(x,y)=(x⁻²+1,y/x³)
to E_a. The second extends across the displayed poles on the smooth projective models. For ω=dX/(2Y),
f1*ω=x dx/y and f2*ω=−dx/y.
They span the holomorphic differentials on C_a. Consequently the induced homomorphism Jac(C_a)→E_a×E_a is an isogeny over Q. The Jacobian rank is twice the elliptic rank, hence two.

Finally j(E_a)=256a³/(a+1), a nonconstant rational function with finite fibers. Infinitely many parameters give infinitely many quotient j-invariants. A fixed smooth genus-two curve has finite automorphism group, hence only finitely many degree-two elliptic quotient isomorphism classes: each such quotient corresponds to its covering involution. Therefore these curves cannot belong to finitely many geometric isomorphism classes.

## Scope

This is an unconditional rational-parameter infinitude theorem, not a statement that every rational parameter has rank one. The interval contains only three integers, so this argument cannot give infinitely many integral parameters. It establishes neither arbitrary prescribed local congruences nor the actual local targets at denominator primes.

In particular, it does not establish infinitely many full depth-two endpoint equalities. Applying the integer endpoint theorems to these rational parameters without a separate analysis of denominator primes would be invalid. The earlier arithmetic prime-pattern criteria remain sufficient, but their infinitude is not proved here.

The companion SymPy script verifies only the displayed identities. The infinitude assertion uses the cited external theorem and its proof.
